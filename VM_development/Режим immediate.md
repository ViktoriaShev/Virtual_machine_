
## Необходимые изменения

### 1. Добавим макросы в `vm.h`:

```c
/* Макросы для декодирования immediate-операндов */
#define FIMM(i)     (((i) >> 8) & 1)           // бит режима immediate (в позиции 8)
#define IMM9(i)     ((i) & 0x1FF)              // 9-битный immediate (поле C)
#define SEXTIMM9(i) sext((i) & 0x1FF, 9)       // знаковое расширение 9 бит

/* Функция знакового расширения */
static inline uint32_t sext(uint32_t n, int b) {
    return ((n >> (b - 1)) & 1) ? (n | (0xFFFFFFFF << b)) : n;
}
```

### 2. Модифицируем `funcs.c`:## Ключевые изменения:

### 1. **Макросы для immediate операндов:**

- `FIMM(i)` - проверяет 8-й бит (режим immediate)
- `IMM9(i)` - извлекает 9-битное значение
- `SEXTIMM9(i)` - знаковое расширение до 32 бит
- `Cv_or_imm(i)` - возвращает либо значение из регистра C, либо immediate

### 2. **Функции с поддержкой immediate:**

✅ **Арифметика:** `add`, `sub`, `mul`, `div`, `mod`, `expt` ✅ **Логика:** `and`, `or`, `xor` ✅ **Сравнения:** `eq`, `ne`, `gt`, `ge`, `lt`, `le` ✅ **Время:** `add_time`, `sub_time` ✅ **Строки:** `left`, `right`, `mid`, `insert`, `delete`, `replace` ✅ **Таймеры:** `ton`, `tof`, `tp` ✅ **Счётчики:** `ctu`, `ctd` ✅ **Прочее:** `limit`, `mux` ✅ **Переходы:** `jmp`, `jmp_if`, `jmp_if_not`

### 3. **Функции БЕЗ immediate (требуют адреса):**

- `concat` - требует два адреса строк
- `sel` - требует адрес базы
- `ctud` - использует оба входа (C не может быть immediate)

### 4. **Формат инструкции:**

```
[ OpCode:7 ][ IMM_bit:1 ][ A:8 ][ B:8 ][ C:9 ]
                ^--- бит 8 определяет режим
```

Когда `bit[8] == 1`, поле C интерпретируется как знаковое 9-битное immediate значение вместо номера регистра.
