## Ключевые изменения:

### 1. **Макросы для immediate операндов:**

- `FIMM(i)` - проверяет 8-й бит (режим immediate)
- `IMM8(i)` - извлекает 8-битное значение

## Режим Immediate — Полное описание

### Макросы декодирования (vm.h)

```c
/* Макросы для декодирования immediate-операндов */
#define FIMM(i)     (((i) >> 8) & 1)           // бит режима immediate (позиция 8)
#define IMM8(i)     ((i) & 0xFF)               // 8-битный immediate (поле C)
#define SEXTIMM8(i) sext((i) & 0xFF, 8)        // знаковое расширение 8 бит

/* Функция знакового расширения */
static inline uint32_t sext(uint32_t n, int b) {
    return ((n >> (b - 1)) & 1) ? (n | (0xFFFFFFFF << b)) : n;
}

/* Универсальный геттер для операнда C */
#define Cv_or_imm(vm, i) (FIMM(i) ? SEXTIMM8(i) : vm->reg[RC(i)])
```

### Формат инструкции с Immediate

```
┌─────────┬─────────┬─────────┬───┬─────────┐
│ Opcode  │    A    │    B    │ I │   C/IMM │
│ 7 бит   │  8 бит  │  8 бит  │ 1 │  8 бит  │
└─────────┴─────────┴─────────┴───┴─────────┘
  31..25    24..17    16..9     8    7..0
                                 ^
                                 └─── IMM-бит (0=регистр, 1=константа)
```

**Интерпретация поля C:**

- `IMM=0` → C — индекс регистра (0–255): `reg[C]`
- `IMM=1` → C — знаковая константа (-128..+127) с автоматическим расширением до 32 бит

### Операции с поддержкой Immediate

**✅ Полная поддержка (операнд C):**

|Группа|Операции|
|---|---|
|**Арифметика**|`add`, `sub`, `mul`, `div`, `mod`, `expt`|
|**Логика**|`and`, `or`, `xor`|
|**Сравнения**|`eq`, `ne`, `gt`, `ge`, `lt`, `le`|
|**Время**|`add_time`, `sub_time`|
|**Строки**|`left`, `right`, `mid`, `insert`, `delete`, `replace`|
|**Таймеры**|`ton`, `tof`, `tp` (ID в immediate)|
|**Счётчики**|`ctu`, `ctd` (preset в immediate)|
|**Управление**|`limit`, `mux`|
|**Переходы**|`jmp`, `jmp_if`, `jmp_if_not` (адрес в immediate)|
|**Детекторы**|`rising_edge`, `falling_edge`, `edge_both` (ID в immediate)|
|**Защёлки**|`rs_latch`, `sr_latch` (ID в immediate)|
|**Демультиплексор**|`demux` (индекс в immediate)|

**❌ БЕЗ поддержки Immediate:**

- `concat` — требует два адреса строк (оба должны быть в регистрах)
- `sel` — требует адрес базы (должен быть в регистре)
- `ctud` — использует оба входа UP и DOWN (C не может быть immediate)

### Примеры использования

```assembly
; ===== Арифметика =====
ADD  R1, R2, #10         ; R1 = R2 + 10
SUB  R3, R4, #-5         ; R3 = R4 - (-5) = R4 + 5
MUL  R5, R6, R7          ; R5 = R6 * R7 (без immediate)

; ===== Сравнения =====
GT   R1, R10, #100       ; R1 = (R10 > 100) ? 1 : 0
EQ   R2, R5, R6          ; R2 = (R5 == R6) ? 1 : 0

; ===== Таймеры =====
TON  R1, R10, #500       ; Таймер ID из R1, preset=500мс
TOF  R2, R11, R8         ; Таймер ID из R2, preset из R8

; ===== Детекторы =====
RISING_EDGE R1, R10, #3  ; Детектор ID=3, вход=R10
FALLING_EDGE R2, R11     ; Детектор ID из R2, вход=R11

; ===== Защёлки =====
RS_LATCH R1, R7, R8, #5  ; Защёлка ID=5, S=R7, R=R8

; ===== Демультиплексор =====
DEMUX R5, R10, #7        ; mem[R10 + 7*4] = R5

; ===== Переходы =====
JMP #0x3000              ; Безусловный переход на адрес 0x3000
JMP_IF R5, #0x4000       ; Если R5≠0, переход на 0x4000
```

### Преимущества Immediate-режима

1. **Компактность кода** — нет необходимости загружать константы в регистры
2. **Производительность** — меньше обращений к памяти
3. **Читаемость** — явное указание констант в коде
4. **Диапазон** — знаковые константы от -128 до +127 покрывают большинство случаев
