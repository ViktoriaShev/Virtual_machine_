## Обзор

VM32 — специализированная 32-битная виртуальная машина, разработанная для выполнения программ промышленных программируемых логических контроллеров (ПЛК). Архитектура соответствует стандартам **IEC 61131-3** и обеспечивает полный набор функциональных блоков для промышленной автоматизации.

### Ключевые особенности

-  **Циклическая модель выполнения** — детерминированные циклы ПЛК с контролем времени
-  **Контроль целостности** — CRC32-хеширование состояния между циклами
-  **IEC 61131-3 совместимость** — стандартные таймеры (TON/TOF/TP) и счётчики (CTU/CTD/CTUD)
-  **64 МБ памяти** — линейное адресное пространство с побайтовой адресацией
-  **256 регистров** — 32-битные регистры общего назначения
-  **Immediate-операнды** — поддержка констант в инструкциях для оптимизации

## Архитектура

### Основные характеристики

|Параметр|Значение|
|---|---|
|**Разрядность**|32 бита|
|**Объём памяти**|64 МиБ (67 108 864 байта)|
|**Регистры**|256 × 32-битных|
|**Формат инструкций**|Фиксированный, 32 бита|
|**Порядок байтов**|Little-Endian|
|**Опкоды**|128 (расширяемо до 127)|

### Формат инструкции

Каждая инструкция занимает ровно **32 бита**:

```
┌─────────┬─────────┬─────────┬───┬─────────┐
│ Opcode  │    A    │    B    │ I │   C/IMM │
│ 7 бит   │  8 бит  │  8 бит  │ 1 │  8 бит  │
└─────────┴─────────┴─────────┴───┴─────────┘
  31..25    24..17    16..9     8    7..0
```

**Поля:**

- **Opcode** (7 бит) — код операции (0–127)
- **A** (8 бит) — регистр назначения (результат)
- **B** (8 бит) — первый операнд (регистр)
- **IMM** (1 бит) — режим immediate: 0 = регистр C, 1 = константа
- **C** (8 бит) — второй операнд (регистр или signed immediate)

**Immediate-режим**: Бит 24 определяет, как интерпретировать поле C:

- `IMM=0` → C — индекс регистра (0–511)
- `IMM=1` → C — знаковая константа (-256..+255) с автоматическим расширением до 32 бит

## Модель выполнения

### Циклическая архитектура ПЛК
![[General_chart_of_vm.drawio.svg]]
VM32 работает в режиме **детерминированных циклов**, типичном для промышленных контроллеров:

```
╔═══════════════════════════════════════════════════════════╗
║  ЦИКЛ N                                                   ║
╠═══════════════════════════════════════════════════════════╣
║  1. Вычисление хеша регистров (начало цикла)             ║
║  2. Выполнение программы от PC_START до HALT/EXIT         ║
║  3. Обновление всех таймеров (TON/TOF/TP)                ║
║  4. Вычисление хеша регистров (конец цикла)              ║
║  5. Проверка целостности (сравнение с предыдущим циклом)  ║
║  6. Контроль времени выполнения (cycle_time_ms)          ║
║  7. Пауза до начала следующего цикла                      ║
╚═══════════════════════════════════════════════════════════╝
```

### Конфигурация VM

```c
typedef struct {
    uint32_t cycle_time_ms;      // Время цикла ПЛК (по умолчанию 1000 мс)
    uint32_t clock_rate_hz;      // Ограничение скорости (0 = без лимита)
    bool enable_cycle_check;     // Предупреждение о перерасходе времени
    bool enable_hash_check;      // CRC32-контроль между циклами
    bool enable_tick_timing;     // Точное ограничение тактовой частоты
    hash_algorithm_t hash_algo;  // HASH_CRC32 или HASH_SIMPLE_FNV1A
} vm_config_t;
```

**Пример настройки:**

```c
vm_config.cycle_time_ms = 100;        // Цикл 100 мс (10 Гц)
vm_config.enable_hash_check = true;   // Проверка целостности
vm_config.hash_algo = HASH_CRC32;     // CRC32 для надёжности
```

### 1. Арифметические операции (с immediate)

|Опкод|Мнемоника|Операция|Immediate|
|---|---|---|---|
|0|**ADD**|`A ← B + C`|✅|
|1|**SUB**|`A ← B - C`|✅|
|2|**MUL**|`A ← B × C`|✅|
|3|**DIV**|`A ← B ÷ C`|✅|
|4|**MOD**|`A ← B mod C`|✅|
|5|**EXPT**|`A ← B^C`|✅|

**Примеры:**

```assembly
ADD  R1, R2, R3      ; R1 = R2 + R3 (регистры)
ADD  R1, R2, #10     ; R1 = R2 + 10 (immediate)
MUL  R5, R6, #-5     ; R5 = R6 × (-5)
```

|---|---|---|

|8|**LN**|Натуральный логарифм|
|9|**LOG**|Десятичный логарифм|
|10|**EXP**|Экспонента e^x|
|11-16|**SIN/COS/TAN/ASIN/ACOS/ATAN**|Тригонометрия|

### 3. Логические операции (с immediate)

|Опкод|Операция|Immediate|
|---|---|---|
|17|**AND** — `A ← B & C`|✅|
|18|**OR** — `A ← B \| C`|✅|
|19|**XOR** — `A ← B ⊕ C`|✅|
|20|**NOT** — `A ← ~B`|—|

### 4. Сравнения (с immediate)

Все операции записывают в A: `1 (TRUE)` или `0 (FALSE)`

|Опкод|Условие|Immediate|
|---|---|---|
|21|**EQ** — `B = C`|✅|
|22|**NE** — `B ≠ C`|✅|
|23|**GT** — `B > C`|✅|
|24|**GE** — `B ≥ C`|✅|
|25|**LT** — `B < C`|✅|
|26|**LE** — `B ≤ C`|✅|

### 5. IEC 61131-3 Таймеры

VM32 предоставляет **16 экземпляров** каждого типа таймера (ID: 0–15):

#### TON (Timer On-Delay) — Задержка включения

```
IN ──┐     ┌──────────── OUT
     │     │ (preset_ms)
     └─────┘
```

- При переходе `IN: 0→1` начинается отсчёт
- `OUT=1` когда `elapsed ≥ preset_ms`
- При `IN=0` выход немедленно сбрасывается

#### TOF (Timer Off-Delay) — Задержка выключения

```
IN ────────┐
           │ (preset_ms)
OUT ───────┴──────────
```

- Пока `IN=1` → `OUT=1`
- При `IN: 1→0` выход остаётся активным `preset_ms`

#### TP (Timer Pulse) — Генератор импульса

```
IN  ─┐
     │
OUT  └───────┐
     (fixed) │
             └─────
```

- Фронт `IN: 0→1` генерирует импульс длительностью `preset_ms`
- Повторные переходы игнорируются до завершения

**Использование:**

```assembly
; TON с ID=2, вход=R10, preset=R5(мс), результат→R1
TON R1, R10, R5      ; reg[1] = ton_Q(2)

; С immediate preset (500 мс)
TON R1, R10, #500
```

### 6. Счётчики

|Опкод|Тип|Описание|Immediate|
|---|---|---|---|
|50|**CTU**|Count Up|✅ preset|
|51|**CTD**|Count Down|✅ preset|
|52|**CTUD**|Up-Down|—|

**Пример:**

```assembly
CTU R3, R10, #100    ; Счёт до 100 (immediate preset)
```

### 7. Переходы (с immediate)

|Опкод|Инструкция|Immediate|
|---|---|---|
|56|**JMP** addr|✅|
|57|**JMP_IF** cond, addr|✅ addr|
|58|**JMP_IF_NOT** cond, addr|✅ addr|

**Примеры:**

```assembly
JMP #0x3100          ; Безусловный переход (immediate адрес)
JMP_IF R5, #0x3200   ; Если R5≠0, переход на 0x3200
JMP R10              ; Переход по адресу из регистра
```

### 8. Управление выполнением

|Опкод|Инструкция|Описание|
|---|---|---|
|59|**EXIT** [code]|Завершение с кодом возврата|
|60|**HALT**|Останов VM|
|61|**NOP**|Нет операции|

## Система контроля целостности

### CRC32-хеширование состояния

VM32 использует **CRC32 (IEEE 802.3)** для проверки детерминизма выполнения:

```c
uint32_t calculate_registers_hash(void) {
    return vm_config.hash_algo == HASH_CRC32 
        ? crc32(reg, sizeof(reg))
        : fnv1a_hash(reg, sizeof(reg));
}
```

**Логика проверки:**

1. **Начало цикла N**: вычисляется `hash_start[N]`
2. **Конец цикла N**: вычисляется `hash_end[N]`
3. **Проверка**: `hash_end[N-1] == hash_start[N]`?
    - ✅ **OK** — состояние стабильно между циклами
    - ❌ **HASH MISMATCH** — обнаружено недетерминированное изменение

**Применение**: Обнаружение race conditions, недетерминированных операций, сбоев памяти.

## Работа с памятью

### Организация памяти

```
┌────────────────────────────────────────┐ 0x00000000
│  Свободная область (12 КБ)             │
├────────────────────────────────────────┤ 0x00003000 ← PC_START
│  Код программы (инструкции)            │
│  ↓ растёт вниз                         │
├────────────────────────────────────────┤
│  Данные, строки, стек                  │
│  (динамическое размещение)             │
├────────────────────────────────────────┤
│  ...                                   │
└────────────────────────────────────────┘ 0x04000000 (64 МиБ)
```

### API доступа к памяти

```c
// Побайтовый доступ
uint8_t  mr8(uint32_t addr);
void     mw8(uint32_t addr, uint8_t val);

// 32-битные слова (Little-Endian)
uint32_t mr32(uint32_t addr);
void     mw32(uint32_t addr, uint32_t val);
```

### Безопасность памяти

Все строковые операции включают **автоматическую проверку границ**:

```c
size_t safe_strlen_at(uint32_t addr);        // Ограниченный strlen
void safe_memmove(uint32_t dest, uint32_t src, size_t n);
```

```bash
gcc -o vm32 vm32.c funcs.c hashing.c timers.c debug.c cleanup.c -lm -O2
```

### Запуск программы

```bash
./vm32 program.bin
```

## Ограничения и масштабирование

### Текущие ограничения

- 128 опкодов (расширяемо до 127)
- 256 регистров
- 16 экземпляров каждого типа таймера/счётчика
- 64 МиБ памяти (фиксировано)
- **Не потокобезопасно** (требуется внешняя синхронизация)

### Защиты

- Максимум 100 000 инструкций за цикл (защита от зависаний)
- Автоматическая остановка при выходе PC за границы памяти
- Валидация опкодов при выполнении

## Расширение функциональности

### Добавление новой инструкции

**1. Прототип в `vm.h`:**

```c
void op_my_instruction(uint32_t i);
```

**2. Реализация в `funcs.c`:**

```c
void op_my_instruction(uint32_t i) {
    uint32_t result = Bv(i) + Cv_or_imm(i);  // С поддержкой immediate
    SetA_val(i, result);
}
```

**3. Регистрация в `vm32.c`:**

```c
op_ex_f op_ex[OPCODE_COUNT] = {
    /* ... */
    op_my_instruction,  // Опкод 62
    /* ... */
};
```
