# 🔍 Почему твоя модель отличная для контроллера

Давай синхронизируемся с требованиями реального головы-по-каналу-runtime.

## ✔ 1. Твои инструкции очень быстрые

Массив функций `op_ex[]` → мгновенный dispatch.  
Это в 2–3 раза быстрее, чем switch-case.  
На embedded — это важно.

## ✔ 2. 256 регистров — золотая середина

- LC-2 с 8 регистрами мал
    
- LuaJIT с "виртуальными" регистрами сложен
    
- 256 регистров дают:
    
    • простоту ISA  
    • возможность обрабатывать сложные операции  
    • низкую нагрузку на память  
    • прямую адресацию → быстро
    

Контроллеру **не нужен стек фреймов и сложность LuaJIT**.

## ✔ 3. Операции PLC (TON/TOF/CTU...) проще реализовать с глобальными регистрами

LuaJIT модель стековых регистров неудобна для TON/TOF:  
нужно хранить struct state → проще иметь прямые memory-адреса.

## ✔ 4. Ты можешь выполнять команды по мере прихода — без генерации кода

Это огромный плюс: LuaJIT-трассировщик тут не нужен.

## ✔ 5. 32-битная инструкция подходит под все твои операции

Чаще всего формат ABC:

```
opcode (7 bits)
A (8 bits)
B (8 bits)
C (9 bits)
```

Покрывает:

- арифметику
    
- строки
    
- сравнения
    
- time/date
    
- память
    
- таймеры PLC
    

Всё идеально укладывается в 32 бита.
