# IEC Types — Architecture Skeleton

## 1. Назначение документа

Данный документ описывает архитектурный каркас системы типов IEC
в проекте **system** на этапе ШАГА 10.

Документ фиксирует:
- назначение системы типов
- основные сущности
- принципы расширения

Реализация значений и операций над типами не рассматривается.

---

## 2. Общая концепция системы типов

Система типов IEC предназначена для:
- описания структуры данных IEC
- обеспечения типобезопасности
- подготовки к вычислению выражений и логики

Типы IEC:
- не хранят значения
- не зависят от Scheduler или Task
- используются как метаданные

---

## 3. IecType

`IecType` — базовый дескриптор типа IEC.

Текущие свойства:
- имя типа

Пример:
```cpp
IecType("INT");
```

`IecType`:
- является неизменяемым объектом
- используется по ссылке
- не содержит логики исполнения

---

## 4. Built-in Types

В проекте определён набор встроенных типов IEC:

- BOOL
- INT
- REAL

Они представлены как **глобальные неизменяемые дескрипторы**.

```cpp
BuiltinTypes::INT
```

Добавление новых типов:
- выполняется централизованно
- не требует изменения существующих компонентов

---

## 5. Связь с IecVariable

Каждая `IecVariable`:
- имеет имя
- имеет ссылку на `IecType`

Таким образом:
- переменная всегда типизирована
- тип отделён от хранения значения

---

## 6. Детерминизм и безопасность

Типовая система проектируется с учётом:
- отсутствия динамического изменения типов
- предсказуемого поведения
- отсутствия RTTI и dynamic_cast

Типы не создаются динамически в runtime.

---

## 7. Ограничения текущего этапа

На текущем этапе отсутствуют:
- значения переменных
- проверки совместимости типов
- операции и выражения
- пользовательские типы (STRUCT, ARRAY)

Все ограничения являются **осознанными**.
