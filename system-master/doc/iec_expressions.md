# IEC Expressions — Architecture Skeleton

## 1. Назначение документа

Данный документ описывает архитектурный каркас системы выражений IEC
в проекте **system** на этапе ШАГА 12.

Документ фиксирует:
- роль выражений в IEC Runtime
- основные сущности
- границы ответственности

Реальная семантика вычислений в документе не рассматривается.

---

## 2. Общая концепция выражений IEC

Выражения IEC предназначены для:
- описания вычислений
- реализации присваиваний
- выполнения логики Program

В текущей архитектуре выражения:
- не вычисляют значения
- не изменяют состояние
- служат структурным каркасом

---

## 3. IecExpression

`IecExpression` — базовый интерфейс любого выражения IEC.

```cpp
class IecExpression {
public:
    virtual ~IecExpression() = default;
    virtual void evaluate() = 0;
};
```

Назначение:
- единый контракт для всех выражений
- точка расширения execution engine

---

## 4. IecAssignment

`IecAssignment` представляет операцию присваивания:

```
target := source
```

Текущая версия:
- хранит ссылки на target и source
- не выполняет копирование значений
- не выполняет проверки типов

Назначение:
- зафиксировать модель присваивания
- подготовить базу для семантики IEC

---

## 5. Связь с Value Storage

Выражения работают с:
- `IecValueRef`
- косвенным доступом к значениям

Это обеспечивает:
- отделение логики от хранения данных
- возможность оптимизаций в будущем

---

## 6. Место выражений в модели исполнения

Упрощённая цепочка исполнения:

```
Scheduler
  -> Task
      -> IEC Program
          -> Expressions
```

Выражения:
- не знают о Scheduler
- не знают о Task
- выполняются в контексте Program

---

## 7. Детерминизм

Система выражений проектируется с учётом:
- строгой последовательности исполнения
- отсутствия скрытых побочных эффектов
- воспроизводимости поведения

Все вычисления будут происходить:
- внутри tick-loop
- в заранее определённом порядке

---

## 8. Ограничения текущего этапа

На текущем этапе отсутствуют:
- арифметические операции
- логические операции
- условные выражения
- управление потоком

Все ограничения являются **осознанными**.
